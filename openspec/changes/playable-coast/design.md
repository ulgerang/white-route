# 설계 결정

- 검증용 브라우저 ES modules와 자체 WebGL 표시를 사용한다. GPU 미지원 시 동일 기하의 Canvas 표시를 제공한다. 이는 최종 상용 엔진 선택이 아니다.
- 규칙은 60Hz 고정 스텝, 입력은 tick 기준 기록, 코스는 시드와 검수된 패턴 블록으로 생성한다.
- 미터/초 단위를 사용하고 수치·위험·수집·분기는 data/coast.json에 둔다.
- 첫 10초는 안전하고, 충돌 후 보호 시간과 패턴 간 회복 공간을 제공한다.
- 구멍/크레바스와 달리 동물 위험은 점프 회피를 요구하지 않는다. 보급 목표는 완주를 막지 않는다.
- 기록과 훈련/보조 결과를 구분하고, 리플레이는 버전·규칙 해시·입력·결과를 다시 검증한다.
- 로컬 저장과 명시적인 JSON 내보내기만 사용하며 외부 계측 전송은 없다.
- 자동 검사와 실제 플레이어/기기 승인을 별도 게이트로 다룬다.
