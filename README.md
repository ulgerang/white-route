# WHITE ROUTE

**하얀 대륙: 펭귄 익스프레스** — 펭귄 전령 루미가 빙판을 달려 기지를 잇는 3D 아케이드 탐험 레이서.

현재 상태: **푸른 해안 코스 1개의 실행 가능한 프로토타입 v0.1.0**. 전체 게임이나 출시 빌드는 아닙니다. 기존 콘셉트 문서와 연구 자료는 그대로 보존했습니다.

## 실행

Node.js **22 이상**에서 실행합니다. 런타임 외부 패키지가 없어 `npm install`은 필요하지 않습니다.

```sh
npm run dev
# 브라우저: http://127.0.0.1:5173
```

같은 네트워크의 휴대폰에서 시험하려면 `npm run dev -- --host 0.0.0.0`으로 실행하고 PC의 사설 IP와 5173 포트에 접속합니다. 신뢰하는 로컬 네트워크에서만 사용하세요.

```sh
npm run validate    # 구문 검사 + 35개 자동 테스트 + 정적 빌드
npm run build       # dist/ 생성
npm run dev -- --dist
```

`dist/`의 파일을 그대로 정적 호스팅에 배치할 수 있습니다. 이 변경은 배포나 GitHub Pages 설정을 자동으로 수행하지 않습니다. `index.html`을 파일 탐색기로 직접 여는 대신 HTTP 서버를 사용하세요.

## 조작

| 행동 | 키보드 | 터치 |
|---|---|---|
| 연속 좌우 조향 | A / D, ← / → | 좌우 버튼 홀드 |
| 가속 / 감속 | W / S, ↑ / ↓ | 가속 / 감속 홀드 |
| 점프 | Space | 점프 버튼 |
| 경로 선택 | 1: 안전, 2: 지름길 | 경로 안내 버튼 |
| 일시정지 / 설정 | Esc | 상단 일시정지 |

첫 화면에서 바로 출발할 수 있습니다. 별도의 훈련 모드는 시간 초과 실패를 없앱니다. 탭 전환이나 창 초점 상실 시 자동으로 일시정지합니다.

## 구현된 범위

- 3.2km 해안 코스, 200초 제한, 첫 10초 이상 안전 구간. 연속 조향, 가감속, 준비→공중→착지 점프, 충돌 후 감속과 보호 시간.
- 얼음 구멍·크레바스·움직이는 물개 3종 위험과 물고기·보급 상자 2종 수집. 동물을 해치지 않으며, 보급 목표를 놓쳐도 완주 가능합니다.
- 안전 경로 / 200m 짧은 위험 경로, 약한 횡풍 구간, 잔여 거리·시간·속도를 구분한 HUD, 결과·손실 원인·즉시 재도전.
- 자체 코드 생성 3D 펭귄·해안·위험물, 효과음, 큰 HUD·고대비·효과 축소·자동 점프 보조, 반응형 터치 입력.
- 시드 기반 코스, 60Hz 고정 규칙 계산, 입력/이벤트 로그 JSON 내보내기·가져오기·재생, 로컬 최고 기록과 설정.

WebGL을 우선 사용하고, 사용할 수 없을 때 동일한 기하와 카메라를 쓰는 Canvas 소프트웨어 3D 표시로 전환합니다. 소프트웨어 모드는 깊이 정렬과 성능이 제한된 호환성 대안입니다.

**아직 포함하지 않음:** 5장/20구간 캠페인, 기지 허브, 체온, 구조 스토리, 장비·꾸미기, 대시, 게임패드·입력 재지정, 온라인 기능, 상용 아트와 음악. 체온과 대시는 초기 코어 검증 범위에서 제외한 기존 기획을 따릅니다.

## 구조와 검증

`data/coast.json`에서 수치와 패턴을 수정합니다. `src/simulation.js`는 DOM/렌더러와 독립된 규칙, `src/renderer.js`는 표시, `src/input.js`는 입력, `src/main.js`는 화면과 실행 흐름입니다.

- [구현 구조·데이터·리플레이](docs/06_technical/prototype-implementation.md)
- [실행한 검증과 미검증 범위](docs/08_qa/prototype-validation.md)
- [기존 기획 문서 목차](docs/README.md)
- [OpenSpec 변경 제안](openspec/changes/playable-coast/proposal.md)

선택적 브라우저 테스트에는 별도로 Python과 Playwright가 필요합니다. 설치한 Chromium 경로는 `--chromium`으로 지정할 수 있습니다.

```sh
python -m pip install playwright
python -m playwright install chromium
python tests/browser_smoke.py --offline
# 서버를 먼저 실행한 일반 HTTP 환경에서는:
python tests/browser_smoke.py --url http://127.0.0.1:5173
```

제작 환경에서 규칙·서버 테스트 **35개**, 오프라인 모듈 브라우저 검사 **21개**가 통과했습니다. 브라우저 검사는 소프트웨어 표시로 수행했습니다. WebGL 실기기, 실제 휴대폰 성능, 오디오 청취, 일반 HTTP 브라우저 로딩, 사람 대상 가독성·재미 검증은 아직 완료하지 않았습니다.

게임은 외부 서버로 플레이 로그를 전송하지 않습니다. 설정과 최고 기록은 브라우저 로컬 저장소에, 입력과 이벤트는 사용자가 내보낸 JSON에만 저장됩니다. 원작 게임의 캐릭터·음악·이미지나 분석 프레임을 런타임 자산으로 사용하지 않습니다.
