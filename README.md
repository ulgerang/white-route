# WHITE ROUTE

남극을 배경으로 한 3D 아케이드 탐험 레이서의 콘셉트 기획 저장소입니다.

- **현재 상태:** 콘셉트 기획 v0.1 (2026-10-03)
- **한 줄 소개:** 빙판 위를 질주하는 펭귄 탐험대가 제한된 시간과 체온으로 기지를 잇고, 날씨와 갈림길을 읽어 구조 임무를 완수합니다.
- **현재 범위:** 제품 비전, 원작·영상 분석, 핵심 게임플레이, 콘텐츠, UX, 아트·오디오 방향, 기술 데이터, 제작 로드맵 및 QA 기준 문서
- **구현 상태:** 플레이 가능한 빌드는 아직 없습니다. 첫 검증 목표는 회색 박스 코스 1개입니다.

문서 목차와 설계 방향은 [`docs/README.md`](docs/README.md)에서 시작하세요. OpenSpec 설정은 [`openspec/config.yaml`](openspec/config.yaml)에 있습니다.

조사 문서에는 참고 영상과 공식 자료가 인용되어 있습니다. 프레임 시트는 분석을 위해 만든 참고 자료이며, 원작 게임의 명칭·캐릭터·음악·아트 자산을 새 게임에 복제하는 것을 목표로 하지 않습니다.
