## 조사 대상

- 제공 영상: [LCH, “[NES] 남극탐험 - LEVEL 3 올 클리어 동영상 [1080p 60FPS]”](https://www.youtube.com/watch?v=DcQg94-cuuQ), 길이 12:59, 게시 2017-09-12. 설명란은 패미컴판과 LEVEL 3 올 클리어 플레이를 명시한다.
- 공식 참고: [닌텐도 Wii 버추얼 콘솔 플레이 안내](https://www.nintendo.co.jp/wii/vc/vc_knd/vc_knd_02.html), [닌텐도 패미컴 설명서 PDF](https://www.nintendo.co.jp/data/software/manual/man_FC4J_00.pdf).
- 영상은 자막이 제공되지 않아 화면과 플레이 흐름이 주 분석 대상이다. 아래 개괄 로그의 시간 표시는 장면 분류용이며, 00:30–00:50 구간은 별도 0.3초/0.1초 이미지 시트로 정밀 표본 분석했다.

## 원작 루프 역기획

1. 시작 화면에서 난이도(Level 1~3)를 고른다.
2. 펭귄이 화면 하단 중앙에 놓이고, 전진하는 빙판 코스를 달린다.
3. 플레이어는 좌우 위치를 조정하고 점프로 얼음 구멍·크레바스를 넘는다. 화면 가장자리 이탈, 장애물 충돌은 진행 손실과 시간 압박으로 이어진다.
4. 물고기와 깃발을 주워 점수를 올리고, 반짝이는 깃발은 프로펠러 효과를 주는 아이템으로 기능한다.
5. 제한 시간 안에 다음 기지에 도달하면 다음 구간으로 진입한다. 영상은 LEVEL 3 설정의 완주 플레이를 보여준다.

닌텐도의 설명은 각 스테이지의 목적지를 제한 시간 안에 통과하는 구조, 실패 시 게임 오버, 구멍·크레바스·물개 회피, 물고기·깃발 수집, 남은 시간 점수 보너스를 확인해 준다. 세부 조작과 수치는 플랫폼 버전에 따라 다를 수 있다.

## 원작의 강점

- 목표가 간단하다: “시간이 다 되기 전에 다음 기지까지 도착.”
- 원근 스크롤로 장애물을 읽고 피하는 행동이 즉시 이해된다.
- 반복 장애물과 정해진 배열이 학습, 예측, 숙련을 만든다.
- 펭귄 캐릭터와 남극 탐험 설정의 친근한 표현이 시간 압박을 경쾌한 도전으로 완충한다. (영상 샘플만으로 음악의 특성은 평가하지 않음)
- 점수와 남은 시간 보너스가 속도와 효율의 동기를 준다.

## 구조적 한계와 기회

| 관찰된 한계 | 개선 가설 |
|---|---|
| 좌우 회피/점프 중심이라 플레이 중 의사결정 폭이 좁음 | 감속, 점프, 대시를 위험 유형에 맞춰 선택하게 함 |
| 반복 구간 숙련은 깊지만 장기 목표가 점수/완주에 치우침 | 구조·보급 임무와 지름길/안전길 보상으로 목적 추가 |
| 충돌 정지와 시간 감소가 겹치면 회복보다 실패가 이어질 수 있음 | 충돌을 단계화하고 회복 조작·무적/복구 창을 제공 |
| 고정 패턴 외의 재플레이 변주가 제한적 | 날씨·시야·노면을 룰 가독성이 유지되는 범위에서 조합 |
| 초보자에게 숨은 물리와 사각 위험이 가혹할 수 있음 | 예고선, 카메라 보정, 연습 모드, 보조 설정 제공 |

## 근거와 제안의 경계

- **근거:** 위의 제한 시간, 스테이지 목적지, 난이도 단계, 위험물, 수집품과 시간 점수 보너스는 닌텐도 설명을 토대로 한다.
- **영상 관찰:** 해당 링크는 LEVEL 3 올 클리어를 표방하는 약 13분 플레이 영상이다. HUD의 스테이지·시간·거리·속도와 `HI` 점수, Stage 10/JAPAN 도착 표식을 확인했다. 점수 산식·정확한 조작 입력·음향은 영상 샘플만으로 확정하지 않는다.
- **기획 제안:** 체온, 구조 임무, 지름길, 대시, 날씨 분기, 캠페인 메타 진행은 새 게임을 위한 제안이며 원작 기능으로 서술하지 않는다.
