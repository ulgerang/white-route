# 역기획 원칙과 발전 방향

## 원작을 이루는 재미 구조

| 원작 요소 | 플레이어 감정 | 유지할 점 |
|---|---|---|
| 자동 전진 주행 | 앞으로 밀려가는 속도감 | 달리기가 기본 상태이며 멈추지 않게 한다 |
| 레인/좌우 위치 선택 | 위험을 읽는 긴장 | 입력은 단순하고 목표 위치는 명확하게 |
| 점프와 장애물 배열 | 반응과 패턴 숙련 | 위험마다 최적 행동이 다른 패턴 구성 |
| 제한 시간과 기지 도착 | 완주 압박과 성취 | 짧고 명확한 구간 목표 |
| 물고기·깃발 점수 | 위험을 감수하는 보상 | 안전한 수집선과 숙련자용 보상선을 분리 |
| 밝은 펭귄 표현 | 위협을 낮춘 유쾌함 | 실패 연출을 가볍고 재도전 친화적으로 |

## 발전 원칙

1. **조작 추가는 목적과 함께:** 버튼 수를 늘리는 게 아니라 기존 회피에 새로운 판단을 더한다.
2. **랜덤은 공정한 예고 후에:** 날씨가 바뀌어도 위험물은 읽혀야 한다. 무작위 생성은 시험된 패턴 블록을 조합한다.
3. **결과에는 회복 선택을 둔다:** 충돌 후에 감속/균형 회복으로 손실을 제한할 수 있어야 한다.
4. **기록과 임무를 병렬 제공:** 기록 경쟁을 좋아하지 않는 플레이어도 탐험대 이야기를 완주할 목표가 있다.
5. **성장은 표현과 선택을 넓힌다:** 업그레이드는 편의와 스타일, 도구 조합을 바꾼다. 기본 이동 숙련보다 우월한 수치만 판매하지 않는다.

## 프레임 분석에서 도출한 설계 개선

| 00:30–00:50 영상 관찰 | 설계상 위험 | 새 게임 반영 |
|---|---|---|
| Stage 01이 이어지는 동안 지형과 작은 오브젝트 배열이 계속 바뀜 | 한 스테이지가 패턴 반복으로 평평하게 느껴질 수 있음 | 스테이지 전환 없이 15~25초 플레이 프레이즈마다 위험 조합, 보상, 회복 구간을 바꾼다 |
| `1P`, `HI`, `TIME`, `REST`, `SPEED` 표시가 상단에 모여 있음 | 작은 글씨/숫자가 주행 판단과 경쟁할 수 있음 | 정보 목적은 유지하되 목적지·시간·속도를 우선하고, 점수는 기록 모드에서만 강조한다 |
| 푸른 틈처럼 보이는 막대와 색상 표식·작은 스프라이트가 함께 나타남 | 장애물·수집물·배경의 의미를 빠르게 구분하기 어려움 | 실루엣과 움직임을 먼저 구분하고 색/소리는 보조 채널로 사용한다 |
| 0.3초 샘플에서는 점프 궤적이 모호했지만, 0.1초 표본에서 00:47.9–00:48.5의 상승·공중·하강이 더 선명해짐. 접촉 여부는 여전히 불명 | 점프·피격이 발생해도 의도와 결과가 전달되지 않을 수 있음 | 점프 준비·공중·착지, 충돌·회복을 서로 다른 시각 피드백으로 명확히 보여준다. 근접 통과와 접촉은 별도 연출로 구분한다 |
| 주황색 동물형 스프라이트가 펭귄 가까이 접근 | 근접 통과와 충돌이 화면에서 혼동될 수 있음 | 동물의 진입 방향을 미리 예고하고, 회피/접촉 결과를 별도 애니메이션으로 구분한다 |

0.1초 정밀 표본은 짧은 애니메이션 상태 전환을 드러내지만 원본 60fps 전체 프레임은 아니다. 영상만으로 확정하지 않은 버튼 입력·충돌·객체 기능은 새 게임의 사실 규칙으로 간주하지 않는다. 관찰/추정/제안의 구분과 시트 링크는 [영상·원작 분석](source-analysis.md)에 기록한다.

## 새 게임의 고유 훅

**“빙판의 길을 읽는 탐험 레이서”** — 눈보라와 갈라진 빙붕 속에서 갈림길을 선택하고, 팀의 체온·구조 물품을 고려해 제시간에 목적지에 도착한다. 짧은 아케이드 주행의 즉시성과 원정 선택의 누적 의미를 함께 제공한다.

## 설계 금지선

- 화면 정보량이 입력 시점의 장애물 판독을 방해하지 않는다.
- 놓친 수집품 때문에 생존/기록이 사실상 불가능해지는 배치를 하지 않는다.
- 날씨 가변성을 플레이어가 원인 파악할 수 없는 충돌로 만들지 않는다.
- 실패마다 장시간의 이동, 반복 대화, 재화 손실을 강제하지 않는다.
- 실제 남극 환경·연구 활동은 존중 있게 표현하고, 허구의 기지/팀을 사용한다.
