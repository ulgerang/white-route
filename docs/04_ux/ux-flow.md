# UX 흐름 및 HUD

## 주요 흐름

기지 허브 → 임무 선택 → 장비/난이도 확인 → 구간 브리핑(짧은 위험 설명) → 주행 → 도착 평가 → 다음 경로/보급 결정 → 원정 결과.

첫 플레이는 허브 설명을 건너뛰고 15초 이내 첫 주행에 진입한다. 첫 구간은 위험 하나씩 짧은 안전 시범으로 가르친다. 일시정지에서 조작표, 접근성 설정, 즉시 재시작을 제공한다.

## 주행 HUD 우선순위

1. **목적지/잔여 거리:** 상단 중앙 또는 주행 방향 표식. 위험 예고 영역과 겹치지 않는다.
2. **시간:** 거리와 가까이 배치하되 라벨/아이콘/단위로 명확히 구분한다.
3. **속도:** 원작 화면에서 확인된 막대형 계기를 현대적으로 단순화하고, 현재 속도와 안정 권장 범위를 읽게 한다.
4. **임무/보조 자원:** 핵심 루프 검증 전 체온·장비 충전은 상시 HUD에서 제외한다. 임무는 현재 목표 하나만 요약한다.
5. **점수/최고 기록:** 기록 모드에서 강조한다. 이야기 모드에서는 보조 정보로 두고 이름을 명확히 쓴다.

## 정보 표시 원칙

- 숫자만으로 위험을 표현하지 않는다. 형태, 방향, 소리 중 적어도 두 채널을 사용한다.
- 위험 신호 색은 수집품/체온과 겹치지 않게 팔레트를 정한다.
- 도착점은 플레이 시야에 마지막 구간을 남기고 등장하며, 화면 밖 거리표를 제공한다.
- 시간 부족 경고는 임계값 한 번만 강하게 알리고, 반복 깜박임/음향 경보는 금한다.
- 위험·수집·장식은 색 하나에 의존하지 않고 실루엣과 진입 동작으로 구분한다. 0.1초 분석에서도 작은 표식과 동물형 스프라이트의 원작 기능은 확정되지 않았으므로, 새 게임 UI는 통과 뒤 획득 아이콘/카운터 갱신으로 결과를 확인시킨다.
- 점프는 준비·공중·착지 상태를, 충돌은 접촉·회복 상태를 시각적으로 구분한다. 00:47.9–00:48.5에서 공중 전환은 읽혔지만 접촉은 확인되지 않았다. 게임에서는 발밑 그림자/착지 표식으로 점프 상태를, 별도 충격 효과와 회복 모션으로 접촉을 알린다.
- 근접 통과에는 충돌 효과를 재생하지 않는다. 충돌이 발생하면 UI/캐릭터/효과음 중 두 채널 이상에서 결과를 알려 원인과 손실을 빠르게 이해할 수 있게 한다.

## 결과 화면

완주/실패 → 달성 임무 → 구간별 손실 원인 → 보상 → 다음 선택/재도전 순서. 첫 노출은 결과 핵심 3항목을 먼저 보여준다. 실패 원인은 가장 큰 손실 요인 한 개를 제시하고 필요하면 상세 내역을 펼친다.
