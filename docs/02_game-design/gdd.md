# 게임 디자인 개요 (GDD)

## 1. 개요

《하얀 대륙: 펭귄 익스프레스》는 기지 사이를 잇는 얼음길을 달리는 3D 아케이드 탐험 레이서다. 고정 화면 하단의 캐릭터와 원근 스크롤을 활용하고, 구간마다 제한 시간·구조 목표·분기 경로를 제공한다.

## 2. 핵심 경험

플레이어는 자동 전진하는 펭귄을 좌우로 유도하고, 제한 시간·잔여 거리·속도를 확인하며 얼음길을 읽는다. 점프는 기본 회피 행동으로 프로토타입에서 검증한다. 대시는 좌우 조향·속도·점프 루프가 충분히 재미있다고 확인된 다음 추가 후보로 둔다. 구간 끝에서는 도착 시간과 수행 임무를 확인하고 다음 경로/보급 결정을 한다.

### 프레임 분석으로 보강한 핵심 요구

- **이벤트 근거:** 00:31.8–00:32.6의 푸른 틈/표식은 펭귄과 겹쳐 보이고 점수가 변하지만, 점프·충돌·획득 중 무엇인지는 영상만으로 판별되지 않는다. 00:47.9–00:48.5에는 펭귄의 상승·공중·하강 상태가 0.1초 표본에서 연속적으로 보여 점프 가능성이 높다. 물개형 객체와의 접촉은 확인되지 않는다.
- **플레이 프레이즈:** 스테이지 번호는 유지하면서 15~25초마다 위험 조합, 보상, 안전 회복 여백을 바꾼다. 표본 구간에서 Stage 01이 유지되는 동안 오브젝트 배열은 계속 변했다.
- **HUD 위계:** 잔여 거리/목적지 → 시간 → 속도/상태 → 점수/선택 임무 순으로 읽힌다. 원작의 `1P`·`HI`·`TIME`·`REST`·`SPEED` 정보 목적은 참고하되 현대 화면에 맞는 글자 크기와 위계를 새로 설계한다.
- **상호작용 가독성:** 위험·수집·배경 오브젝트는 색만으로 구별하지 않는다. 푸른 틈, 초록 표식, 주황 동물형 객체가 작은 표본에서 혼동된 점을 반영해 실루엣·진입 동작·접촉/획득 피드백을 서로 다르게 만든다.
- **행동 상태:** 점프 준비·공중·착지와 충돌 접촉·회복을 명확한 별도 상태로 보여준다. 0.1초 표본에서 공중 전환은 일부 확인됐지만, 입력 버튼 및 충돌/획득 판정은 확인되지 않았으므로 이를 원작 규칙으로 단정하지 않는다.

이 표본 분석은 기능 확정 자료가 아니라 가독성 문제를 찾은 관찰 자료다. 설계 가설은 아래 플레이테스트에서 검증한다: 플레이어가 위험/수집을 구분하는가, 상승·공중·착지를 설명하는가, 근접 통과와 접촉을 구별하는가.

## 3. 게임 모드

- **원정 모드:** 4~6개 구간을 묶어 하나의 구조/보급 원정을 진행한다. 완주와 선택한 분기, 구조 인원이 결과를 만든다.
- **기록 주행:** 고정된 일일 시드 코스에서 점수와 완주 기록을 비교한다. 비동기 고스트/친구 기록은 후속 구현으로 둔다.
- **훈련:** 위험 유형별 짧은 연습, 조작 감도/보정 설정, 원하는 구간 재생을 제공한다.

## 4. 플레이어 능력

| 행동 | 기능 | 상호 보완 |
|---|---|---|
| 좌우 조향 | 연속 이동을 기본 후보로 두고 3레인 보조 이동과 비교 검증 | 장애물 회피, 보상선 선택 |
| 가속/감속 | 순간 속도와 제어 여유 변경 | 기록 점수 vs 정밀 회피 |
| 점프 | 균열·얕은 구멍 횡단 | 착지 공간 필요, 연속 점프 금지 |
| 대시 (후보) | 짧은 전방 돌파 | 핵심 조작이 검증된 후 포함 여부 결정 |
| 회복 | 미끄러짐/충돌 뒤 자동 또는 짧은 타이밍 입력으로 자세 복귀 | 새 버튼을 늘리지 않고 손실을 제한 |

## 5. 긴장과 보상

- 시간은 기지 도착을 재촉하고, 남은 시간은 별 등급과 구조 여유에 반영된다.
- 체온은 눈보라, 차가운 물, 정지 시간에서 떨어지고 쉼터·온풍 장비·구조 동료로 회복된다.
- 보상선은 위험 구간과 가깝게 두되, 필수 임무 아이템은 안전한 대안 경로로도 얻을 수 있게 한다.
- 실패/구간 중단 시 원정 중 획득한 핵심 해금은 유지하고, 해당 구간만 빠르게 재도전할 수 있게 한다.

## 6. 진행 구조

중앙 기지에서 임무를 고르고, 장비 슬롯 최대 2개를 준비한 뒤 출발한다. 구간마다 경로 지도에 두 갈래를 표시한다. 선택 결과는 다음의 노면, 날씨, 보급 기회, 위험도에 영향을 준다. 원정 종료 후 구조 성과와 기록 보상을 지급한다.

## 7. 난이도

기본 난이도는 고정된 공정 패턴과 짧은 튜토리얼로 학습시킨다. 난이도 설정은 충돌 여유, 시간 폭, 예고 시간, 보조 조향의 네 축을 개별 조절할 수 있도록 설계한다. 기록 모드는 조건을 고정해 비교의 공정성을 유지한다.

## 8. 콘텐츠 원칙

각 구간은 하나의 새 질문을 낸다: 어느 쪽으로 움직일까? 속도를 줄일까? 점프할까? 구조 물품을 위험하게 모을까? 대시는 첫 수직 슬라이스 후에도 선택의 폭이 부족할 때만 검토한다. 위험물은 형태·움직임·색상 표식·음향 중 두 가지 이상으로 기능을 읽을 수 있어야 한다.

첫 위험 소개는 단독·저압력 상황으로 배치하고, 플레이어가 대응한 뒤에만 다른 위험과 결합한다. 점프 뒤에는 착지 위치를 읽고 다음 입력을 준비할 안전 간격을 둔다. 물개 등 이동 위험과 겹치는 패턴은 접촉 판정과 회피 가능성을 플레이테스트로 확인하기 전까지 필수 점프 구간으로 사용하지 않는다.

## 9. 비목표

오픈월드 생존 시뮬레이션, 무기 전투, 현실의 기지/인물 재현, 실시간 경쟁 멀티플레이는 초기 범위 밖이다.
