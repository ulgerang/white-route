# 게임플레이 시스템

## 시간과 속도

각 구간은 제한 시간을 갖는다. 가속/감속은 기록 주행의 핵심 조작으로 프로토타입에서 재미와 가독성을 확인한 뒤 점수 효과를 확정한다. 구간 잔여 시간은 완주 등급과 다음 구간의 보급 여유에 영향을 준다. HUD는 시간과 남은 거리를 서로 다른 라벨/아이콘으로 표시한다. 시간은 실패가 임박해도 코스 판독을 해칠 정도로 UI를 점멸시키지 않는다.

## 체온

체온은 **핵심 주행 루프가 검증된 뒤 추가 여부를 결정할 보조 자원**이다. 프레임 분석에서 직접 근거가 나온 기능이 아니며 초기 회색 박스 범위에는 넣지 않는다. 채택하면 고갈이 즉사 조건이 되지 않도록 한다.

- 감소 요인: 강풍 구간 체류, 물에 빠진 뒤 젖음, 일정 시간 이상 가속 지속.
- 회복 요인: 기지 도착, 온열 쉼터, 보온 물품, 구조 동료 동행.
- 낮은 체온 효과: 속도보다 회복 조작 판정과 미끄러짐 안정성에 소폭 영향.
- 경고 구간에서는 UI·캐릭터 떨림·숨소리를 함께 제공하며, 복구 선택지를 화면에 제시한다.

이 시스템은 프로토타입에서 재미·가독성을 먼저 검증한다. 스트레스만 늘면 생존 수치를 제거하거나 환경 버프/디버프로 축소한다.

## 위험물 패턴

00:30–00:50 표본에서 푸른 막대/틈처럼 보이는 물체, 색상 표식, 작은 동물형 스프라이트가 나타났으나 격자 프레임만으로 모두의 기능을 확정할 수는 없었다. 새 게임은 위험·수집·배경 장식을 아래 규칙으로 분리한다.

- **위험:** 고유 실루엣과 접근/공격 모션, 도로 위 그림자 또는 방향 경고를 사용한다.
- **수집:** 별도 모양과 긍정 피드백을 사용한다. 위험과 동일한 모양의 작은 색상 사각형만으로 표시하지 않는다.
- **장식:** 충돌/수집 판정이 없으며 색상·크기·움직임으로 플레이 요소와 혼동되지 않는다.
- 화면에서 기능을 처음 만날 때는 안전한 소개 프레이즈를 둔다. 표식 식별에 실패하면 위험도나 점수를 바꾸기 전 가독성부터 수정한다.

**정밀 표본에서 확인한 상호작용 공백:** 00:32.1–00:32.6의 푸른 형상은 펭귄과 겹치고 점수 변화도 가까이 발생하지만 원인-결과 연결을 확정할 수 없다. 00:47.9–00:48.5에는 펭귄의 공중 상태가 연속 표본에서 나타나며, 주황색 물개형 객체가 가까이 지나간다. 이를 바탕으로 새 게임은 획득, 무피해 근접 통과, 점프 통과, 실제 충돌을 서로 다른 결과 이벤트와 피드백으로 명세한다. 이는 원작의 판정을 추정해 복제하기 위한 근거가 아니다.

| 위험 | 예고 | 적정 대응 | 실패 결과 |
|---|---|---|---|
| 얕은 얼음 구멍 | 어두운 중심부, 깨진 얼음 가장자리, 접근하며 커지는 형태 | 레인 변경 또는 짧은 점프 | 짧은 감속/자동 균형 회복 |
| 긴 크레바스 | 길게 이어진 어두운 틈, 눈 파편 | 넓은 도약 또는 대시 | 크게 감속, 구조물 충돌 시 추가 시간 손실 |
| 물개/야생동물 | 고유 실루엣, 이동 방향과 진입 동작 예고 | 레인 변경·감속. 점프 회피를 요구하려면 점프 가능 여부를 별도 학습시킨다 | 접촉 시 명확한 짧은 회복 피드백. 동물은 해치지 않음 |

| 눈보라 벽 | 원거리 실루엣과 시야 변화 | 표식 따라 감속, 안전 레인 유지 | 속도 손실. 화면 암전/무예고 판정 금지 |

## 수집물

**시각 구분 요구:** 깃발 계열은 읽기 쉬운 깃대/천 실루엣, 물고기/관측물은 각각 다른 형태와 모션을 사용한다. 통과 후에는 작은 점수 상승만이 아니라 짧은 수집 피드백을 줘 획득 여부를 확인시킨다. 00:32대의 점수 변화처럼 주변 이벤트가 겹쳐 인과관계가 헷갈리지 않도록, 보상 수치 옆에 획득 대상 아이콘을 잠시 표시하고 임무 카운터도 같은 이벤트에서 갱신한다.

- **보급품:** 구조 목표와 원정 보급에 쓰인다. 경로 양쪽에 필수 물량 대안 제공.
- **관측 자료:** 위험선이나 지름길 보상. 지역 도감·외형 해금에 반영.
- **기록 표식:** 점수/콤보. 완주 목표와 별도 보상으로 구분.
- **반짝이는 항해 표식:** 한시 도구 충전 또는 일회성 부양. 원작의 반짝 깃발 기능을 그대로 복제하지 않는 새 아트/규칙으로 표현한다.

## 분기 경로

각 선택 지점에는 **안전도, 시간, 보급, 구조 목표** 중 두 항목만 비교 표시한다. 예: “해안 얼음길: 안전↑·보급↑ / 빙붕 지름길: 시간↑·위험↑”. 선택은 짧은 경로표지 구간에서 하고, 노출 동안 되돌릴 수 없다.

## 점수와 등급

점수는 경로 효율, 위험 회피 연속 성공, 선택적 수집에 기반한다. 구간 별 등급은 완주, 임무, 기록 기준의 세 항목을 별도로 판정한다. 생존/구조 완주와 최고 기록 경쟁을 하나의 점수로 강제하지 않는다.

## 실패 상태

충돌 → 짧은 감속/미끄러짐 → 플레이어 복구 입력 기회 → 주행 복귀. 구조 애니메이션 중에는 판정 불가 시간을 명확히 표시한다. 구간 실패는 시간 초과 또는 치명적인 경로 이탈로 한정하고, 랜덤 연속 충돌로 통제력을 빼앗지 않는다.
