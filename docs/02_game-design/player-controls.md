# 플레이어 조작 및 피드백

## 기본 입력 제안

| 행동 | 키보드 | 게임패드 | 홀드/탭 의미 |
|---|---|---|---|
| 좌우 이동 | A/D 또는 ←/→ | 왼쪽 스틱/십자키 | 연속 조향을 기본 후보로 시험하고, 한 번 탭에 한 레인 이동하는 보조 모드도 비교 |
| 가속 | W 또는 ↑ | RT | 홀드 동안 속도·점수 계수 증가 |
| 감속 | S 또는 ↓ | LT | 제어 여유 증가, 시간/속도 점수 감소 |
| 점프 | Space | A/Cross | 준비·공중·착지 상태를 명확히 표시. 높이 조절은 검증 후 결정 |
| 대시 (후보) | Shift | X/Square | 첫 조작 프로토타입에서 필요성이 확인된 경우에만 포함 |
| 일시정지 | Esc | Menu | 원정·튜토리얼 상황 보존 |

모바일은 출시 플랫폼 검증 뒤 결정한다. 터치 입력을 넣을 경우 좌우 가상 스틱보다 스와이프/별도 액션 영역을 비교 테스트한다.

## 이동 감각 목표

- 방향 입력 후 이동 시작 지연은 감지할 수 없을 정도로 짧게 하되, 최고 속도에서 급회전이 무조건 정답이 되지 않도록 관성을 둔다.
- 화면 하단의 기준 위치에 펭귄을 두고 코스가 다가오는 표현과, 펭귄이 좌우로 더 이동하는 표현을 비교 테스트한다. 원작 영상만으로 레인 수나 카메라/월드 이동 규칙은 확정하지 않는다.
- 기본 주행 속도는 안정적인 첫 회피가 가능한 수준으로 설정한다.
- 가속은 기록에 유리하되 반응 시간이 줄고 체온 소모가 조금 커지는 위험/보상 선택이다.
- 감속은 시간을 소모하지만 착지·좁은 길에서 정밀도를 회복한다.
- 점프 준비 동작·공중 상태·착지 동작을 끊김 없이 구분한다. 영상의 00:47.9–00:48.5에서 상승·공중·하강은 보였으나 입력과 착지 판정의 근거는 없었다. 새 게임은 발밑 그림자/착지 표식, 캐릭터 자세, 착지 효과를 조합해 공중과 지면을 빠르게 읽게 한다.
- 충돌 시 접촉 순간, 자세 손실, 회복 종료를 각각 다른 시각/청각 신호로 알린다. 물개형 위험과 펭귄이 가까이 보인 영상 장면만으로는 실제 접촉 여부를 구분할 수 없었으므로, 무피해 근접 통과와 실제 접촉의 결과 신호를 명확히 분리한다.
- 점프가 위험 회피의 필수 행동이라면 점프 전 예고와 착지 공간을 보장한다. 아직 검증하지 않은 동물형 위험을 점프로만 피하게 하는 패턴은 만들지 않는다.

## 카메라와 조준

카메라는 캐릭터 후방 약간 위의 고정 추적 시점. 플레이어 이동에 따라 화면을 과하게 흔들지 않고, 멀리 있는 장애물의 크기와 간격이 일정한 곡선으로 확대된다. 곡선 코스는 카메라 회전보다 지형 프레임 이동으로 표현해 입력 방향의 혼동을 줄인다.

## 접근성 옵션

- 조향 보조 강도, 점프 자동 입력 보조, 입력 재지정, 홀드/토글 선택
- 카메라 흔들림, 눈보라 입자, 번쩍임, 화면 흔들림 개별 조절
- 위험물 형태 아이콘/색약 팔레트, 큰 HUD, 자막 및 효과음 시각 표시
- 시간 압박 완화, 충돌 회복 창 확대, 훈련의 무실패 모드

## 햅틱/사운드 피드백

안전한 착지는 가벼운 탁 소리, 미끄러짐은 좌우로 흐르는 짧은 진동, 큰 충돌은 한 번의 낮은 타격음으로 구분한다. 반복 진동으로 방향 정보를 전달하지 않는다. 음소거 상태에서도 위험 신호는 애니메이션/아이콘으로 보인다.
