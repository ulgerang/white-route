# 핵심 플레이 루프

## 순간 루프 (1~8초)

**위험 예고 → 방향/속도 판단 → 조향 또는 점프 → 통과/접촉 판정 → 거리·시간·상태·점수 피드백**

위험물과 수집물은 실루엣과 움직임으로 우선 구분하고 색/소리를 보조 채널로 쓴다. 종류별로 적어도 한 번의 방향/행동 결정이 가능한 예고 구간을 보장한다. 위험 대응을 익히기 전에는 속도 보너스로 예고 시간을 줄이지 않는다. 시간·거리·속도만으로 순간 판단이 충분한지 먼저 검증한 뒤 체온 등의 보조 자원을 추가한다.

### 상호작용 이벤트 단위

점프가 필요한 구간은 **위험 예고 → 이륙 → 공중 통과 → 착지 확인 → 다음 행동 준비**가 끊기지 않게 구성한다. 00:47.9–00:48.5 표본에서는 상승·공중·하강 전환은 읽혔지만 입력과 접촉 결과는 확인되지 않았다. 따라서 게임에서는 점프 성공을 발밑 그림자와 착지 피드백으로 알리고, 실제 접촉은 별도 충격·자세 손실 피드백으로 표시한다. 착지 직후에는 다음 위험을 피할 최소 안전 공간을 확보한다.

수집물·위험물의 통과 결과도 분리한다. 수집은 획득 애니메이션과 점수/목표 갱신으로, 근접 통과는 무피해 상태로, 접촉은 충돌 및 회복 상태로 표시한다. 초록/주황 객체나 푸른 틈이 한 장면에 겹쳐도 판정이 한 가지 시각 신호에만 의존하지 않게 한다.

## 구간 루프 (2~4분)

1. 출발 위치에서 현재 구간 임무를 확인한다.
2. 전진하며 위험, 날씨, 수집물을 읽는다.
3. 경로 분기 또는 구조/보급 우선순위를 선택한다.
4. 기지에 도착해 시간, 체온, 구조 목표, 점수를 판정한다.
5. 다음 구간 선택이나 짧은 재시도를 결정한다.

### 구간 내부 리듬

스테이지 하나를 15~25초 플레이 프레이즈로 나눈다: **안전 주행 → 새 위험/표식 소개 → 대응 조합 → 짧은 회복 지대**. 00:30–00:50 표본에서는 Stage 01을 유지한 채 작은 오브젝트와 틈이 연이어 등장했다. 새 설계는 스테이지 전환 없이 이 패턴 단위로 변화를 줘 반복감을 낮춘다.

## 원정 루프 (15~25분)

**임무 게시판 → 장비 선택 → 4~6개 구간 주행 → 중간 보급/경로 결정 → 목적지 도착 → 구조 결과/보상 → 기지 개선/새 임무**

원정 실패는 임무 전부의 리셋이 아니다. 체크포인트에서 구간 단위 재도전을 허용하며, 완주 기록 도전은 별도 규칙으로 운영한다.

## 보상 경제

- **탐사 배지:** 구간 임무·별 등급으로 획득. 기지/캐릭터 꾸미기, 새 경로/장비 선택지 해금.
- **기록 메달:** 순수 주행 성과로 획득. 랭킹·고스트 기록에 사용.
- **구조 기록:** 원정 서사 및 기지 인물/지역 로그를 해금.

화폐 간 환전은 초기 버전에 넣지 않는다. 보상은 세션 종료 후 명확하게 제공하고, 반복 노가다로 필수 진행이 잠기지 않도록 한다.

## 재도전 설계

- 구간 실패 후 2개 버튼 이내에 재시작 가능.
- 같은 구간 재시도 시 성공한 수집 목표나 튜토리얼 완료 상태를 유지한다.
- 실패 이유는 아이콘+짧은 문구로 한 문장에 표시: “눈보라 속도에서 균열 착지 실패”.
- 원정 체크포인트는 직전 구간 종료 시 저장한다.
