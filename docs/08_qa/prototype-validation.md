# 프로토타입 검증 기록

2026-10-03 · 프로토타입 v0.1.0. 이 문서는 실제 실행한 검사와 아직 실행하지 못한 검사를 구분한다.

## 자동 검사

`npm run validate` — Node 22 환경의 구문 검사, **35/35 테스트**, 정적 빌드 통과.

규칙·데이터 검사는 시드 결정성, 150개 시드의 안전 공간, 10초 안전 도입, 고속 예고 거리, 연속 조향, 가감속, 점프 단계, 세 속도에서 자동 점프, 물개 접촉, 충돌 보호, 단일 수집 보상, 선택적 임무, 근접 통과, 분기/거리 변화, 시간 초과, 훈련 모드, 재생 일치와 잘못된 입력 거부를 포함한다. HTTP 서버 검사는 허용 경로, MIME, HEAD, 비허용 메서드와 디렉터리 탈출 거부를 포함한다.

`python tests/browser_smoke.py --offline --chromium /usr/bin/chromium` — Chromium 소프트웨어 표시에서 **21/21 검사**, 잡히지 않은 JS 페이지 오류 0개. 개별 검사 이름은 [기계 판독 결과](prototype-browser-results.json)에 있다.

브라우저 검사는 실제 HTML·CSS·ES 모듈·JSON을 로컬 메모리로 로드하고 제어된 RAF 시계로 가속한다. 중간 프레임의 표시만 생략하고 게임 규칙과 UI 처리는 그대로 실행한다. 키보드 조향·점프, 정지/재개, 설정, 초점 손실 자동 정지, 결과·실패·재도전, 리플레이 가져오기, 모바일 뷰포트의 복수 터치와 취소를 확인했다.

## 환경 한계

제작 환경에서 로컬 URL 탐색은 관리자 정책으로 차단되어 정상 HTTP 탐색 대신 오프라인 모듈 하네스를 사용했다. 정책을 수정하거나 우회하지 않았다. 또한 WebGL 컨텍스트를 생성할 수 없어 소프트웨어 3D로 검사했다.

따라서 다음 항목을 통과했다고 주장하지 않는다: 일반 HTTP 브라우저 모듈 로딩, WebGL 셰이더 실행, 실제 휴대폰 GPU/FPS, 교차 브라우저 결정성, 효과음 청취, 디스크 다운로드 UI, 재접속 후 저장 지속성, 사용자 5명의 가독성·재미 평가. HTTP 서버 자체는 별도 Node 테스트에서 요청했다. 자동화의 모바일 뷰포트/합성 터치는 실물 스마트폰 테스트가 아니다.

GitHub Actions용 규칙 검사 워크플로를 제공하지만 위 결과는 로컬 제작 환경의 실행 기록이다. 원격 CI 성공 여부는 실제 해당 실행 결과로 별도 확인해야 한다. 배포 URL은 이 변경으로 생성되지 않는다.
