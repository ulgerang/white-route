# 승인 기준 및 플레이테스트 계획

## 회색 박스 프로토타입 기준

- 입력 지연/카메라 방향 때문에 의도와 다른 레인으로 가는 문제가 재현되지 않는다.
- 위험 예고 시점에 좌우 이동 또는 점프 중 최소 하나를 실행할 시간이 있다.
- 동일한 시드와 입력에서 결과가 재현된다.
- 구간 리셋은 2초 이내 진입을 목표로 한다.
- 장애물 하나의 실수만으로 연쇄 충돌이 불가피해지지 않는다.
- 감속·가속이 점수/시간/안정성 중 눈에 보이는 차이를 만든다.
- 신규 플레이어가 HUD의 잔여 거리·제한 시간·속도 표시를 각각 설명할 수 있다.
- 위험/수집/배경 객체의 목적을 색 외의 형태 단서로 구분할 수 있다.
- 점프 준비·공중·착지를 연속해서 구분하고, 실제 충돌을 근접 통과와 구분할 수 있다.
- 수집 시 획득한 대상과 증가한 점수/임무 수량이 서로 연결되어 보인다.

## 플레이테스트 질문

1. 첫 실패 후 무엇이 원인이었는지 말할 수 있었나?
2. 속도 조절이 필요한 상황을 한 번 이상 식별했나?
3. 점프와 대시가 다른 문제를 해결한다고 느꼈나?
4. 수집품을 놓쳐도 완주가 가능하다고 느꼈나?
5. 체온/날씨가 재미있는 선택을 만들었나, 단지 주의를 분산했나?
6. 실패 직후 다시 시도하고 싶은가? 망설이는 이유는 무엇인가?
7. 방금 얻은 보상이 어떤 객체에서 나왔는지 바로 말할 수 있었나?
8. 위험을 피해 지나간 것과 실제로 부딪힌 것을 구분할 수 있었나?

## 필수 시나리오

- 초보 첫 실행: 설명 최소화 상태에서 첫 장애물 대응.
- 고속 상태: 예고 거리 최소값에서 가장 긴 크레바스 회피.
- 충돌 회복: 위험 두 개 사이에 충돌 후 회복 가능한 공간 확인.
- 날씨: 눈보라에서도 위험물 색 외 단서로 판독 가능.
- 접근성: 색약 팔레트/큰 HUD/조향 보조 조합에서 동일 목표 완료.
- 재현성: 저장된 시드와 입력 로그로 충돌 상황 재현.
- 이벤트 판독: 플레이어가 00:47.4–00:48.5 유형의 이동 위험+점프 시퀀스를 플레이한 뒤, 점프 준비·공중·착지와 근접 통과/접촉을 설명할 수 있는지 확인한다. 영상 시트는 설계 리뷰 자료이며 원작 입력이나 충돌 판정의 증거로 사용하지 않는다.
- 수집 인과 판독: 위험/수집 객체가 인접해 나타나는 장면에서 어떤 대상이 획득됐는지와 점수/임무 갱신을 연결해 말할 수 있는지 확인한다.
- 샘플 간격 기준: 0.3초는 패턴 리뷰용이고, 0.1초는 짧은 이벤트 후보 구간을 찾고 상태를 비교하는 용도다. 최종 애니메이션·충돌 판정은 60fps 연속 재생 및 게임 내 재현으로 확인한다.
- 초기 판독 목표(가설): 5명 이상의 첫 플레이어 중 4명 이상이 위험/수집 목적과 점프/접촉 결과를 도움 없이 맞게 설명한다. 목표 미달 시 실패 지점을 시트와 플레이 녹화로 좁혀 실루엣, 예고 시간, 결과 피드백 중 원인을 수정한다. 표본이 작으므로 통계적 품질 보증이 아닌 반복 개선 게이트로 사용한다.

## 밸런스 계측 지표

구간 완료율, 시도 횟수, 최초 위험 인지율, 위험별 충돌률, 회복 시간, 레인 이동 횟수, 행동별 사용 맥락, 분기 선택률, 재시도 지연시간을 본다. 평균만 보지 않고 초보/숙련 및 보조 설정별로 나눠 해석한다.
