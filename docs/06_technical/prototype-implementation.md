# 해안 프로토타입 구현 노트

기준: 2026-10-03 · 빌드 0.1.0 · 원본 기획 기준 커밋 `fcde13aa0d654e97f17dd2a17fe078c65c13bf9e`.

## 범위와 기술 결정

[제작 로드맵](../07_production/roadmap-and-risks.md)의 첫 코스와 코어 검증을 구현한다. 엔진이 미정이므로 설치 비용을 낮춘 브라우저 ES modules / WebGL을 검증용으로 선택했다. 이 선택은 최종 상용 엔진이나 모바일 출시 플랫폼을 확정하지 않는다. Node 22 이상은 개발 서버·테스트·빌드에만 필요하며, 게임 런타임에는 외부 라이브러리·CDN이 없다.

지금은 1코스의 시작→주행→완주/시간 초과→결과→재도전이 연결된다. 안전/위험 분기는 같은 주행 축 위에서 패턴과 실제 종점 거리를 바꾸는 논리적 분기이며, 완전한 다중 도로 그래프는 아니다. 물고기와 보급 상자는 선택적 보상이다. 체온·대시·허브·캠페인·게임패드·멀티플레이·상용 콘텐츠는 보류한다.

## 레이어

| 위치 | 책임 |
|---|---|
| `data/coast.json` | 속도·점프·시간·판정·보상·패턴·경로·약한 횡풍 수치 |
| `src/simulation.js` | 데이터 검증, 시드 코스 생성, 상태 전이, 판정, 이벤트, 리플레이 |
| `src/renderer.js` | 자체 기하 생성, 투영·안개·지형·펭귄 애니메이션, GPU/CPU 표시 |
| `src/input.js` | 키보드, 복수 포인터 홀드, 1회성 점프/경로 입력 |
| `src/audio.js` | 사용자 동작 이후 활성화되는 합성 효과음 |
| `src/main.js` | 고정 스텝 루프, UI·설정·저장·결과·재생 연결 |
| `scripts/` | 안전한 정적 서버, 구문 검사, 배포용 복사 빌드 |

규칙 모듈은 DOM, WebGL, 시간 API, 로컬 저장소를 참조하지 않는다. 화면은 판정을 소유하지 않고 같은 시뮬레이션 상태를 읽는다. `window.whiteRoute`는 QA용 복사 상태·요약·진단·내보내기만 노출하며 실행 상태 수정 API는 제공하지 않는다.

## 데이터와 시간

프로토타입 내부 좌표는 **미터**, 속도는 m/s, 시간은 초다. 이는 원 기획의 정규화 좌표 스키마 예시를 실행용으로 구체화한 결정이다. 콘텐츠 ID는 `CH01_SEG01` 등을 유지한다. 초기 3200m·200초·기본 18m/s·가속 26m/s는 검증용 가설이지 최종 밸런스가 아니다.

시뮬레이션은 60Hz 한 스텝씩만 전진한다. 렌더 간격이 달라도 입력은 해당 tick에 정규화하여 적용된다. 렌더링이 오래 멈추면 무제한 따라잡기를 하지 않는다. 숨김/초점 상실은 자동 정지하고, 재개 시 누적 시간과 홀드 입력을 비운다. 실제 저성능 기기에서의 속도 체감은 후속 성능 검증 대상이다.

시드 PRNG는 검수 가능한 패턴의 레인/변형을 고른다. 전체 지형을 무제약으로 무작위 생성하지 않는다. 첫 위험은 최고 속도 기준 10초 안전 구간 뒤에 나온다. 위험 행 사이 회복 공간과 최소 하나의 안전 레인을 유지한다. 위험·수집·장식은 클래스와 실루엣이 다르며, 장식은 충돌/수집 판정을 갖지 않는다.

## 규칙과 피드백

점프는 준비·공중·착지 상태이며 발밑 그림자는 지면에 남는다. 구멍과 크레바스는 좌우 회피 또는 충분한 점프로 통과한다. 물개는 점프로 피하도록 가르치지 않으며 접촉 시 회피 실패로 처리한다. 접촉은 시간 손실, 짧은 감속, 이후 보호 시간을 적용한다. 보호 시간의 다른 접촉은 추가 손실을 만들지 않는다. 근접 통과와 점프 통과는 접촉 효과와 별도다.

진행 방향 판정은 이동 구간을 검사해 고속에서 얇은 객체를 건너뛰지 않게 한다. 선택적 수집은 한 번만 보상하고 같은 이벤트에 점수/임무 증분과 객체 ID를 기록한다. 분기는 안내가 열린 뒤 한 번 확정하며, 선택하지 않으면 게이트 통과 위치에 따라 결정한다. 위험 경로는 200m 짧고 추가 위험이 생긴다. 시간 초과만 현재 실패 조건이며 도로 바깥은 경계로 제한한다.

## 저장과 재현

코스 데이터의 정렬된 JSON에서 FNV 기반 `config_hash`를 계산한다. 이는 재현 버전 식별용이지 보안 해시가 아니다. JSON 리플레이에는 `schema`, `build`, `config_hash`, 시드, 보조/훈련 설정, 종료 tick, 변경된 입력 패킷, 결과 요약, 이벤트를 담는다. 같은 규칙의 `replayRun`으로 다시 계산한 요약이 기록과 다른 경우 거부한다. 입력 순서·숫자 범위·종료 상태·파일 크기·최대 tick도 제한한다.

확인된 결정성은 동일 런타임·데이터·입력 범위다. 부동소수점과 삼각함수를 사용하므로 서로 다른 브라우저 엔진 사이 비트 단위 일치까지 보증하지 않는다. 입력 기록은 디버깅 용도이며 온라인 순위의 부정행위 방지 증명이 아니다.

설정과 최고 기록은 try/catch로 보호한 localStorage에 저장하며 차단된 환경에서도 게임은 계속 실행된다. 기록 키는 설정·시드·규칙 해시를 구분한다. 재생은 최고 기록을 갱신하지 않는다. 계측 서버/분석 SDK/계정/개인정보 전송은 없다.

## 렌더러와 자산

모든 펭귄·물개·물고기·상자·빙판·산·표식은 코드로 생성한 기하다. WebGL을 만들 수 없으면 같은 기하와 투영을 Canvas에 정렬해 그린다. 이 CPU 표시는 제한적 호환 경로이며 GPU 깊이 버퍼와 완전히 같지 않다. 실기기의 WebGL 셰이더 실행과 성능은 별도 확인해야 한다. 합성 효과음만 있으며 원작 영상과 분석 프레임은 런타임에 포함하지 않는다.

## 후속 승인 게이트

일반 브라우저 HTTP 로딩, WebGL 기기, 터치 실기기, 저장 지속성, 효과음 청취, 교차 브라우저 리플레이를 검증한다. 기존 [승인 기준](../08_qa/acceptance-criteria.md)의 초보 5명 대상 형태/점프/접촉 판독은 자동 테스트 통과와 별개다. 코어 재미와 가독성이 승인된 뒤 체온·임무·대시의 필요성을 다시 판단한다.
