# 세계관과 스테이지 설계

## 세계관

가까운 미래, 여러 연구 거점을 지원하는 가상 남극 보급망에 작은 펭귄 운송대가 있다. 플레이어는 길 찾기에 능한 전령 ‘루미’와 탐험대를 이끌어 통신이 끊긴 기지와 야생동물을 돕는다. 현실 국가 기지의 정확한 지리·연구 내용 대신 허구의 협력 거점과 교육용 환경 설명을 사용한다.

## 진행 지도

| 장 | 환경 테마 | 새로 배우는 것 | 감정/목표 |
|---|---|---|---|
| 1. 푸른 해안 | 넓은 해빙, 낮은 바람 | 레인 이동, 구멍, 점프 | 조작 학습과 첫 구조 |
| 2. 바람의 능선 | 횡풍 능선 | 가속/감속, 바람 방향 | 바람에 맞서는 리듬 |
| 3. 크레바스 지대 | 좁은 빙하 협곡 | 긴 도약, 착지 위치 | 경로 선택의 긴장 |
| 4. 하얀 정전 | 눈보라, 표지 등 | 시야와 청각 보조 | 읽기와 침착함 |
| 5. 새벽의 빙붕 | 부서지는 빙판, 해안 빛 | 익힌 행동 조합 | 대형 구조와 마무리 |

## 구간 템플릿

각 구간은 출발 10초 안전 구간 → 핵심 학습 → 회복/보상 선택 → 숙련 조합 → 명확한 도착 예고의 리듬을 갖는다. 첫 노출은 단일 위험으로, 두 번째는 다른 행동과 조합해, 세 번째는 선택 보상으로 재사용한다.

스테이지 내부는 15~25초 플레이 프레이즈로 나누어 위험 조합·수집·회복 구간을 교차한다. 영상 표본에서는 Stage 01이 유지되는 동안 지형과 작은 객체 배열이 계속 달라졌다. 새 게임은 스테이지 전환 없이도 이런 리듬 변화를 만들고, 새 표식 종류는 안전한 단독 노출로 소개한다.

## 패턴 문법

- 최소 안전 레인 수와 점프 착지 공간을 플레이테스트로 정한다.
- 서로 무관한 치명 위험이 동시에 겹치는 무예고 패턴은 만들지 않는다.
- 각 패턴은 저속/정속/고속 세 조건에서 충돌률을 기록한다.
- 날씨 변형은 판독 불가능한 화면 가림 대신 노면 마찰, 측풍, 예고 표시 방식에 영향을 준다.
- 반복 패턴 사이에 안전 회복 공간을 배치해 연속 실수의 눈덩이화를 막는다.
- 위험·수집·장식은 별도의 모양 언어를 사용한다. 격자 시트에서 기능이 모호했던 스프라이트는 의미를 명확히 하거나 제거한다.
- 점프/충돌처럼 짧은 상태는 실제 플레이 중 즉시 판독돼야 한다. 0.1초 표본에서 00:47.9–00:48.5의 상승·공중·하강은 더 선명해졌지만 접촉은 판정할 수 없었다. 제작 검토에서는 0.1초 시트로 후보 구간을 찾고, 최종 판정은 60fps 연속 재생 및 조작 재현으로 확인한다.

### 참조 이벤트: 이동 위험과 점프

00:47.4–00:48.5 표본은 주황색 물개형 객체의 접근과 펭귄의 공중 상태가 가까운 시간대에 나타나는 사례다. 새 게임에서 이 조합을 쓸 때는 동물의 진행 방향과 충돌 경로를 먼저 예고하고, 점프를 요구한다면 착지 가능 구역까지 미리 보여준다. 첫 소개에서는 동물 또는 틈 중 하나만 위험으로 두고, 대응을 학습한 뒤에만 둘을 함께 배치한다. 실제 원작에서 해당 점프가 물개 회피였다고 확정하지 않는다.

## 콘텐츠 표기 규칙

콘텐츠 ID는 `CH##_SEG##_PAT##`로 쓴다. 예: `CH02_SEG03_PAT02`. 각 항목에는 위험 조합, 시간 예산, 목표 등급, 필수/선택 보상, 난이도, 튜토리얼 참조를 기록한다.
