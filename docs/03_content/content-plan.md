# 콘텐츠 제작 계획

콘텐츠별 에셋 수량·ID·검수 기준은 [에셋 목록 및 제작 기준](../05_art-audio/asset-list.md)을 따른다. 콘텐츠 수량과 에셋 생산량이 달라지면 두 문서를 함께 갱신한다.

## 첫 공개 빌드

- 완결 가능한 1개 원정, 4개 구간
- 해안과 크레바스 2개 환경, 날씨 1종
- 5종 위험/수집 상호작용, 기본 장비 2개
- 1개 캐릭터, 꾸미기 3종, 튜토리얼과 훈련
- 설정 메뉴의 핵심 접근성 항목과 로컬 결과 기록

## 출시 콘텐츠 가설

- 5개 환경 테마, 환경당 4개 수제 구간 = 기본 20개 구간
- 스토리 원정 5장, 구간 도전 변형, 고정 시드 기록 주행
- 주요 캐릭터 4종은 꾸미기/음성 차이 중심. 고유 능력은 밸런스 검증 전 보류.
- 위험물은 8종 이내로 제한하고, 조합과 기상으로 변주한다.
- 지역 로그/도감은 선택 콘텐츠로 두고 주행 중 정독을 요구하지 않는다.

## 반복 콘텐츠 생성 규칙

무작위 구간 생성기는 프로토타입 이후 판단한다. 도입 시 검수된 패턴 블록, 안전 공간, 시간 예산, 난이도 상한을 데이터 규칙으로 제한한다. 생성 시드와 패턴 버전을 저장해 리플레이/버그 재현을 지원한다.

## 보상 구성

- 스토리: 기지 장식, 캐릭터 의상, 지도 일지, 새 환경/임무.
- 실력: 기록 메달, 타임 트라이얼 배지, 유령 기록.
- 접근성/훈련: 학습을 위한 보상 제한 없음. 쉬운 설정 사용이 해금 차단으로 이어지지 않는다.
