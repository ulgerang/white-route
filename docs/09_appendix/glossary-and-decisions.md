# 용어 및 결정 기록

## 용어

| 용어 | 뜻 |
|---|---|
| 구간 (Segment) | 기지와 기지 사이의 완결 가능한 주행 단위 |
| 원정 (Expedition) | 여러 구간과 임무 선택을 묶은 플레이 세션 |
| 레인 (Lane) | 플레이어가 선택하는 좌우 이동 경로 영역 |
| 리드 타임 (Lead time) | 위험 예고가 화면에 보인 시점부터 충돌 예상 시점까지의 시간 |
| 안전 공간 | 회피나 착지 후 다음 행동을 준비할 수 있도록 확보된 구간 |
| 패턴 시드 | 재현 가능한 위험 배치/날씨 선택 정보 |

## 결정 기록

| ID | 결정 | 상태 | 근거/다음 검증 |
|---|---|---|---|
| D-001 | 빠른 아케이드 주행을 핵심으로 하고 생존 시뮬레이션은 피한다 | 제안 | 첫 플레이테스트에서 루프 이해도 확인 |
| D-002 | PC 키보드/게임패드를 첫 플랫폼 가설로 둔다 | 미확정 | 사용자 목표 플랫폼과 제작 환경 확인 필요 |
| D-003 | 체온은 즉사 게이지가 아니라 제어 여유에 영향 | 제안 | 플레이테스트에서 유지/축소/제거 결정 |
| D-004 | 원작 외형·캐릭터·음악을 복사하지 않고 별도 IP로 개발 | 원칙 | 콘셉트 아트/사운드 리뷰에서 점검 |
| D-005 | 전체 랜덤 대신 검수된 패턴 조합부터 시작한다 | 제안 | 반복 플레이 데이터 이후 생성 범위 검토 |
| D-006 | 수집 성공, 근접 통과, 점프 통과, 실제 충돌을 서로 다른 게임 이벤트와 피드백으로 처리한다 | 제안 | 초보자 플레이테스트에서 획득 원인과 접촉 여부를 설명하는지 확인 |
| D-007 | 0.1초 이미지 시트는 짧은 이벤트 검토용이며 최종 판정은 60fps 연속 재생/게임 재현으로 한다 | 작업 기준 | 00:30–00:50 분석의 한계와 제작 검증 방식을 반영 |

## 미결정 항목

- 최종 게임명, 엔진, 팀 규모, 예산, 지원 플랫폼 및 판매 모델
- 세션/콘텐츠 수량의 실제 제작 가능성
- 대시가 조작감 개선에 기여하는지 여부
- 체온, 구조 임무의 핵심 루프 기여도
- 현지화 언어, 등급 심의, 온라인 순위표/고스트 범위
- 제공 영상의 입력 버튼, 점수 변화의 정확한 원인, 객체별 충돌 판정 및 프레임 단위 수치 검수
